# Bundled fonts

The application serves these files locally. No font CDN is contacted at runtime.

- Pretendard Variable **1.3.9**: [official release tree](https://github.com/orioncactus/pretendard/tree/v1.3.9), `packages/pretendard/dist/web/variable/woff2/PretendardVariable.woff2`. License: [Pretendard-OFL.txt](Pretendard-OFL.txt).
- JetBrains Mono **2.304**: [official release tree](https://github.com/JetBrains/JetBrainsMono/tree/v2.304), `fonts/webfonts/JetBrainsMono-Regular.woff2` and `JetBrainsMono-SemiBold.woff2`. License: [JetBrainsMono-OFL.txt](JetBrainsMono-OFL.txt).

Unmodified upstream font files are redistributed under the SIL Open Font License 1.1.
